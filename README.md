# 🚀 Bitscale UI Clone

A responsive UI clone of the Bitscale GTM platform dashboard, built with Next.js 15, Tailwind CSS, and shadcn/ui as part of a frontend assessment.

## ✨ Features

- 🌙 Dark mode toggle
- 🔍 Find People modal with collapsible filters and tag inputs
- 🏢 Find Companies modal with industry and funding filters
- ➕ New Grid modal with source type selection
- 🔎 Live search on grids table
- 💀 Skeleton loaders on dashboard mount
- 📊 Animated stat counters on load
- 🖱️ Row hover actions (Edit, Duplicate, Delete)
- 📱 Responsive sidebar with Coming Soon toasts
- 👤 GTM Spaces workspace switcher

## 🛠️ Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- lucide-react
- next-themes
- react-hot-toast

## 🏃 Getting Started

git clone https://github.com/SambhavSharma7781/bitscale-ui.git
cd bitscale-ui
npm install
npm run dev

Open http://localhost:3000
